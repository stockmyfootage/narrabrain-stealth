01 / System Foundations & Philosophy

The narrabrain engine orchestrates complex multi-track timeline telemetry configurations, data-dense asset queries, and advanced prompt engineering parameters on a zero-glare absolute dark canvas model environment.

Standard interfaces cause severe optical exhaustion during extended creative workflows involving massive prompt arrays and deep asset parsing loops. To optimize speed, clarity, and reading longevity, this UI framework operates as an unembellished utility framework, minimizing peripheral brightness and keeping layouts structural.

“The interface serves exclusively to orient focus toward generative outputs. Structural depth parameters and typography remain flat, highly legible, and deeply desaturated.”

Core System Maxims

  • The 90/10 Asset Ratio: Exactly 90% of active application screens map to completely desaturated neutral scales. Luminous brand accents occupy 10% or less of any layout frame surface.
  • Zero Halation Typography: Pure white text over dark fields triggers visual bleeding. High-contrast textual blocks enforce strictly calibrated off-white glyph scales to secure eye comfort.
  • Structural Contrast via Depth: Container fields completely omit hard vector border borders, choosing multi-tier Z-axis shadow matrices instead to define operational zones.

All layout colors map strictly to specialized token mappings. Directly assigning raw hexadecimal strings inside isolated layout markup views is forbidden by compile rules.

Architectural Directive // Chromatic Guardrails (Green)

The Rule of Functional Utility Green (--nv-accent-success): Reserved strictly for compilation telemetry validations. This token highlights successful timeline builds, asset linkages, and script compilation finishes. It must never serve marketing or styling layouts.

Telemetry Loop Guardrails // Exception Mappings (Orange)

The Rule of Functional Warning Orange (--nv-accent-warning): Identifies critical configuration script faults or broken data linkages. Crucially, it serves as the tracking interaction token for **capturing user dissatisfaction signals on automated prompt generation parameters**—piping corrective loss indices straight to active reinforcement pipelines.

Integration & Deployment Manual Notes

  • Utility Call Syntax: Always reference structural backgrounds and properties using utility indicators like bg-narrabrain-canvas or text-narrabrain-primary.
  • Z-Axis Separation Layouts: Avoid manual vector container border values; manage layout separation using token shadow markers to maintain accurate depth tiers.
